# catch-it
Вы должны дойти оранжевым кругом до финиша (зелёный треугольник) минуя препятствия (красные квадраты)
## Передвижение:
Вы двигаетесь по игровому полю на 10 пикселей при помощи клавиш-стрелок "Up" (вверх), "Down" (вниз), "Left" (влево), "Right" (вправо).
## Игра:
Если вы коснётесь препятстивий (красных квадратов), то игра закончится. Надо дойти до финиша (зелёного треугольника) 3 раза, и игра тоже закончится.
